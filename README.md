# Intelligent Rumor Detection in Social Media Using RNN and NLP

## Overview
This project utilizes Recurrent Neural Networks (RNN) and Natural Language Processing (NLP) techniques to detect rumors and misinformation in social media content.

## Features
- Text Preprocessing
- Tokenization
- Sequence Modeling
- Rumor Classification
- Sentiment Analysis

## Technologies Used
- Python
- TensorFlow
- Keras
- NLTK
- Pandas

## Dataset
Social media posts dataset containing labeled rumor and non-rumor content.

## Results
- Effective rumor classification
- Improved misinformation detection performance
